Análise de desvio

Como medir a discrepância entre os dados e o modelo?

ESTAT0092 – Modelos Lineares Generalizados
Prof. Dr. Sadraque E. F. Lucena
http://sadraquelucena.github.io/mlg

Introdução

  • Já vimos que é possível comparar modelos usando um teste global da razão de veorssimilhanças.
  • Hoje vamos nos debruçar um pouco mais sobre a significância global de um modelo usando o desvio.

Na regressão linear

  • Considere dois modelos de regressão linear normal encaixados: \[ \begin{cases} M_0:& Y_i=\beta_0+\varepsilon_i\\ M_1:& Y_i=\beta_0+\beta_1x_i+\varepsilon_i \end{cases} \]

  • O modelo \(M_1\) acrescenta a covariável \(x\).

  • Ao estimar seus parâmetros por mínimos quadrados, a soma de quadrados residual não aumenta: \[ SQE(M_1)\leq SQE(M_0). \]

  • A diferença \(SQE(M_0)-SQE(M_1)\) mede quanto a inclusão de \(x\) diminui a variação residual.

  • Mas essa redução, sozinha, não responde se o ganho é grande em relação à variabilidade residual e ao custo de adicionar um parâmetro.

    • Para isso, usamos o teste F de comparação entre modelos encaixados.

O que muda nos MLG?

  • Em um MLG, a resposta pode ser binária, uma contagem ou uma variável contínua com outra distribuição.
  • A diferença \(Y_i-\widehat{\mu}_i\) não fornece, por si só, uma medida universal e comparável da discrepância.
  • Por exemplo:
    • Na regressão logística, \(Y_i\) assume 0 ou 1, enquanto \(\widehat{\mu}_i=\widehat{p}_i\) é uma probabilidade.
    • Na regressão de Poisson, a variância condicional muda de acordo com o valor da média.
  • Precisamos, portanto, de uma medida de discrepância coerente com a distribuição probabilística especificada para o MLG: o desvio (deviance).

Equivalência

  • A ANOVA na regressão linear é substituída pela Análise de Desvio em um MLG. A única diferença é que trocamos a Soma de Quadrados pela Deviance e o Teste F pelo Teste da Razão de Verossimilhanças.

Três modelos para entender o desvio

  • Para entendermos o desvio, precisamos entender a definição de 3 modelos:

    • Modelo nulo: Contém apenas o intercepto. Não utiliza as covariáveis para explicar diferenças entre as médias condicionais.
    • Modelo ajustado: É o modelo de interesse, com um conjunto definido de preditores. Ele busca representar os dados com uma estrutura mais simples que a do modelo saturado.
    • Modelo saturado: Possui número de parâmetros igual ao número de observações coletadas nos dados. Serve como referência de ajuste máximo, mas normalmente não é útil para explicar ou resumir os dados.

  • Obs.: O modelo saturado é uma referência matemática, não necessariamente um modelo que deveríamos usar para previsão ou interpretação.

O que é o desvio?

  • O desvio mede a discrepância entre o modelo ajustado e o modelo saturado, comparando suas log-verossimilhanças máximas: \[ D=2\{\ell(\text{modelo saturado})-\ell(\text{modelo ajustado})\} \]

  • Aqui, \(\ell\) representa a log-verossimilhança maximizada.

  • Mantidas a família probabilística e as condições de comparação, o modelo saturado alcança uma log-verossimilhança pelo menos tão alta quanto a do modelo ajustado; por isso, o desvio é não negativo.

  • Interpretação: quanto menor o desvio, mais próximo o modelo ajustado está do modelo saturado em termos de log-verossimilhança.

    • Cabe lembrar que isso não garante, por si só, adequação absoluta nem bom desempenho fora da amostra.

Desvio escalonado

  • O Desvio (\(D\)) mede a “distância” total entre o modelo saturado e o modelo ajustado.

  • Porém, um erro de \(100\) é grande ou pequeno? Depende da dispersão dos dados (\(\phi\)).

    • Se a dispersão (\(\phi\)) for \(1.000\), um erro de \(100\) é pequeno.
    • Se a dispersão (\(\phi\)) for \(0{,}1\), um erro de \(100\) é gigantesco.

  • Nesse caso, podemos utilizar o Desvio Escalonado (\(D^*\)): \[ D^*=\frac{D}{\phi} \]

  • Para famílias como binomial e Poisson, a dispersão é frequentemente fixada em \(\phi=1\), e o desvio e desvio escalonado coincidem.

  • R ou Python geralmente imprimem no summary o Desvio Não Escalonado (\(D\)).

Desvio escalonado

  • O devio escalonado pode ser usado com duas finalidades:
    1. Avaliando UM modelo isolado: O Teste de Qualidade do Ajuste (Goodness-of-Fit).
    2. Avaliando VARIÁVEIS sequencialmente: A Tabela ANODEV (A ANOVA dos MLGs).

1. Testando a Qualidade do Ajuste de um Modelo

  • Uma vez que o Desvio Escalonado (\(D^*\)) mede a distância entre o Modelo Ajustado e o Modelo Saturado (ajuste perfeito), ele ode ser usado como uma meidade de qualidade do ajuste (goodness-of-fit).
  • Sob condições regulares, \(D^* \sim \chi^2_{n-p}\) (\(n\) observações, \(p\) parâmetros).
  • Se \(D^* < \chi^2_{n-p, 1-\alpha} \implies\) Não há evidência de falta de ajuste (O modelo é adequado).
  • Como o valor esperado de uma \(\chi^2_{n-p}\) é \(n-p\), um valor de \(D^*\) próximo de \(n-p\) pode ser um indicativo de que o modelo ajustado aos dados é adequado.
  • Regra de bolso: \(\frac{D^*}{n-p}\approx 1 \implies\) o modelo está bem ajustado aos dados.

1. Testando a Qualidade do Ajuste de um Modelo

No R:

# Ajuste do modelo
modelo <- glm(y ~ x1 + x2, family = gamma(link = "log"))

# Desvio não escalonado (D)
D <- deviance(modelo)

# Estimativa da dispersão (phi)
phi <- summary(modelo)$dispersion

# Desvio Escalonado (D*)
D_star <- D / phi


  • Em famílias como Poisson e Binomial, \(\phi = 1 \implies D^* = D\).
  • Em famílias como Gama, Normal e Gaussiana Inversa, \(\phi\) precisa ser estimado \(\implies D^* = D / \hat{\phi}\).

2. Análise de Desvio (ANODEV)

  • ANODEV é a ANOVA para os MLGs.

  • Na análise de desvio é um procedimento para avaliar a relevância de variáveis explicativas em MLGs.

  • Ele é estatisticamente mais preciso e robusto que o teste de Wald em amostras pequenas e moderadas, além de evitar distorções graves (como o efeito Hauck-Donner).

  • Aqui, as variáveis explicativas são adicionadas uama a uma (de forma sequencial) e mede quanto o desvio cai a cada passo: \[\text{Modelo Nulo } (M_0) \xrightarrow{+A} M_1 \xrightarrow{+B} M_2 \xrightarrow{+A:B} M_3\]

  • Se a redução no desvio for significativa, a variavel deve permanecer no modelo.

2. Análise de Desvio (ANODEV)

  • Para comparar dois modelos encaixados (\(M_p\) com \(p\) parâmetros e \(M_q\) com \(q\) parâmetros, \(p < q\)), a estatística do LRT é dada pela diferença de desvios.

    • Para Binomial e Poisson (\(\phi=1\)), usa-se diretamente o Teste LRT (\(\chi^2\)).: \[ T_{\text{LRT}} = \frac{D_p - D_q}{\phi} \sim \chi^2_{q-p} \quad (\text{quando } \phi \text{ é conhecido}) \]

    • Para famílias como Gaussiana, Gama e Normal Inversa (\(\phi\neq 1\)), utiliza-se a estatística do Teste F: \[ F = \frac{(D_p - D_q) / (q - p)}{\hat{\phi}_m} \sim F_{q-p, \, n-m} \]

2. Análise de Desvio (ANODEV)

Considere uma sequência de entrada \(M_0 \to A \to A+B \to A+B+AB\):

Modelo G.L. Desvio Residual Redução do Desvio (\(\Delta D\)) Teste LRT (\(\phi = 1\)) Teste F (\(\phi\) estimado)
Nulo \(n - 1\) \(D_0\) — — —
A \(n_A - 1\) \(D_A\) \(D_0 - D_A\) \((D_0 - D_A) \sim \chi^2_{n_A - 1}\) \(\frac{(D_0 - D_A)/(n_A-1)}{\hat{\phi}_m} \sim F\)
A + B \(n_B - 1\) \(D_{A+B}\) \(D_A - D_{A+B}\) \((D_A - D_{A+B}) \sim \chi^2_{n_B - 1}\) \(\frac{(D_A - D_{A+B})/(n_B-1)}{\hat{\phi}_m} \sim F\)
A + B + AB \((n_A-1)(n_B-1)\) \(D_{A+B+AB}\) \(D_{A+B} - D_{A+B+AB}\) \(\Delta D_{AB} \sim \chi^2_{(n_A-1)(n_B-1)}\) \(\frac{\Delta D_{AB}/\text{GL}_{AB}}{\hat{\phi}_m} \sim F\)

2. Análise de Desvio (ANODEV)

No R:

# 1. Ajuste do modelo completo com interações
modelo_gama <- glm(yield ~ lineage + epoca + lineage:epoca, 
                   family = Gamma(link = "log"), data = cotton)

# 2. Gerando a Tabela ANODEV via Teste F (pois phi é estimado na Gama)
anova(modelo_gama, test = "F")

# 3. Caso fosse um modelo Poisson ou Regressão Logística (phi = 1)
modelo_poisson <- glm(counts ~ A + B, family = poisson)
anova(modelo_poisson, test = "LRT")
