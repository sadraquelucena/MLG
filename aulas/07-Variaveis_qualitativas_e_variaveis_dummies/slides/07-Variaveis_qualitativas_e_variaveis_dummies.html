Variáveis qualitativas e variáveis dummy

Como representar categorias no preditor linear dos MLGs

Prof. Dr. Sadraque E. F. Lucena

O problema da especificação

Em um MLG, temos \[ g(\mu_i)=\eta_i=\beta_0+\beta_1x_{i1}+\cdots+\beta_px_{ip}. \]

  • Cada componente que entra em \(\eta_i\) precisa possuir uma representação numérica coerente com a estrutura do modelo.
  • Como se dá a representação de uma variável qualitativa$
    • Se a variável Possui imóvel próprio (\(x\)) foi codificada como
      • x = 1 (sim)
      • x = 2 (não)
    não podemos interpretar os códigos 1 e 2 como uma escala quantitativa.

Dummy: a ideia

  • Uma variável dummy assume apenas os valores 0 ou 1.

  • Ela representa a presença de uma categoria em relação a uma categoria de referência. \[ x = \begin{cases} 0,&\text{referência}\\ 1,&\text{categoria de interesse} \end{cases} \]

  • Isso permite adicionar uma variável qualitativa no preditor linear de forma interpretável.

  • No modelo: \(\eta = \beta_0 + \beta_1 \,(\texttt{possui imóvel próprio})\)

    • Se a referência é não, temos:
      • Não possui imóvel próprio (possui imóvel próprio = 0): \(~\eta = \beta_0\)
      • Possui imóvel próprio (possui imóvel próprio = 1): \(\qquad\eta = \beta_0 + \beta_1\)
    • \(\beta_1\) representa o impacto na resposta em relação à categoria de referência.

\(k\) categorias → \(k-1\) dummies

  • Se \(x\) possui \(k\) categorias, definimos uma como referência e criamos \(k-1\) dummies.
  • Por quê?
    • Se criarmos \(k\) dummies, temos a seguinte restrição linear exata: \[x_1 + x_2 + \dots + x_k = 1\]
    • Essa soma gera multicolinearidade perfeita entre as colunas da matriz de dados ao considerar o intercepto (\(\beta_0\)), tornando impossível estimar os parâmetros de forma única.

Exemplo com 3 categorias

  • Considere a variável \(X \in \{A, B, C\}\) com \(A\) como categoria de referência: \[ x_B = \begin{cases} 1, \text{se } X = B\\ 0, \text{caso contrário} \end{cases} \qquad \text{e} \qquad x_C = \begin{cases} 1, \text{se } X = C\\ 0, \text{caso contrário} \end{cases} \]
  • Modelo: \(\eta = \beta_0 + \beta_B x_B + \beta_C x_C\)
Categoria (\(x\)) \(x_B\) \(x_C\) Preditor Linear (\(\eta\))
\(A\) (Referência) 0 0 \(\eta_A ​= \beta_0\)
\(B\) 1 0 \(\eta_B ​= \beta_0​+\beta_B\)
\(B\) 0 1 \(\eta_C ​= \beta_0​+\beta_C\)
  • \(\beta_B\) e \(\beta_C\) representam o impacto na resposta causado pela mudança da categoria \(A\) para as categorias \(B\) e \(C\), respectivamente.

Impacto da Função de Ligação

1. Ligação Identidade (\(\mu = \eta\))

  • Comparações diretas na escala original: \[ \mu(x=1) - \mu(x=0) = \beta_1 \implies \boxed{\beta_i = \text{diferença entre as médias}} \]
  • Exemplo: \(\widehat{\beta}_1 = 4{,}2\) → O grupo sem imóvel próprio apresenta média estimada \(4{,}2\) unidades superior ao grupo com imóvel próprio, mantendo as demais covariáveis constantes.

Impacto da Função de Ligação

2. Ligação Log (\(\log(\mu) = \eta\))

  • Comparações relativas (multiplicativas): \[\log(\mu_1) - \log(\mu_0) = \beta_1 \quad \implies \quad \log\left(\frac{\mu_1}{\mu_0}\right) = \beta_1\]

\[\boxed{\frac{\mu_1}{\mu_0} = e^{\beta_1} = \text{Razão de Médias}}\]

  • Exemplo: \(\widehat{\beta}_1 = 0{,}3 \Rightarrow e^{\widehat{\beta}_1}=e^{0{,}3} = 1{,}35\) → A média esperada do grupo sem imóvel próprio é \(1{,}35\) vezes a média do grupo com imóvel próprio (ou seja, \(35\%\) maior), mantendo constantes as demais covariáveis.

Impacto da Função de Ligação

3. Ligação Logit (\(\text{logit}(\mu) = \log\left(\frac{\mu}{1-\mu}\right) = \eta\))

  • Comparações em termos de chance (odds): \[\operatorname{logit}(\mu_1) - \operatorname{logit}(\mu_0) = \beta_1 \quad \implies \quad \log\left(\frac{\operatorname{odds}_1}{\operatorname{odds}_0}\right) = \beta_1\]

\[\boxed{\frac{\operatorname{odds}_1}{\operatorname{odds}_0} = e^{\beta_1} = \text{Razão de Chances (Odds Ratio)}}\]

  • Exemplo: \(\widehat{\beta}_1 = 0{,}693 \Rightarrow e^{\widehat{\beta}_1}=e^{0{,}693} = 2{,}0\) → A chance (odds) de ocorrer o desfecho no grupo sem imóvel próprio é \(2\) vezes a chance do grupo com imóvel próprio (\(100\%\) maior), mantendo constantes as demais covariáveis.

Modelo com Interação (Duas Variáveis Binárias)

  • O termo de interação permite que o efeito de uma variável dependa do nível de outra: \[\eta = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \beta_{12} (x_1 x_2)\]

  • O produto \((x_1 x_2)\) assume valor 1 apenas quando \(x_1 = 1\) e \(x_2 = 1\) simultaneamente (zero nos demais casos).

  • A combinação das duas variáveis binárias gera 4 cenários no preditor linear:

\(x_1\) \(x_2\) Termo de interação (\(x_1x_2\)) Preditor Linear (\(\eta\))
0 0 0 \(\eta_{00} ​= \beta_0\)
1 0 0 \(\eta_{10} ​= \beta_0​+\beta_1\)
0 1 0 \(\eta_{01} ​= \beta_0+\beta_2\)
1 1 1 \(\eta_{11} ​= \beta_0​+\beta_1+\beta_2+\beta_{12}\)

Interpretação do Coeficiente de Interação (\(\beta_{12}\))

  • \(\beta_{12} = 0\): Não há interação (efeitos são puramente aditivos).
  • \(\beta_{12} > 0\): O efeito de \(x_2\) é potencializado (mais forte) quando \(x_1 = 1\).
  • \(\beta_{12} < 0\): O efeito de \(x_2\) é atenuado (mais fraco) quando \(x_1 = 1\).

Exemplo

Avaliar impacto do Ensino Superior (\(x_1\)) e do Gênero (\(x_2\)) no Salário (\(\eta\) em mil R$). - \(x_1\): \(0 =\) sem superior, \(1 =\) com superior - \(x_2\): \(0 =\) homem, \(1 =\) mulher \[ \text{Salário} = 3 + 2 \, x_1 + 1 \, x_2 + 1{,}5 \, (x_1 x_2) \]

  • Calculando o efeito do Ensino Superior (\(x_1\)) no Salário:
    • Para Homens (\(x_2 = 0\)):
      • Sem superior: \(3\) \(\qquad\circ\,\) Com superior: \(3+2 = 5\)
      • Aumento: \(+R\$ 2.000\) (\(\beta_1\))
    • Para Mulheres (\(x_2 = 1\)):
      • Sem superior: \(3 + 1 = 4\) \(\qquad\circ\,\) Com Superior: \(3 + 2 + 1 + 1{,}5 = 7{,}5\)
      • Aumento: \(+\text{R\$ } 3.500\) (\(\beta_1 + \beta_{12}\))
  • Interpretação de \(\beta_{12} = 1{,}5\): O retorno financeiro do diploma superior é \(R\$ 1.500\) MAIOR para mulheres do que para homens.

Tratamento Automatizado de Fatores no R

No R, não é necessário criar as variáveis dummies manualmente. A função factor() faz a gestão automaticamente.

# 1. Converter para fator e definir rótulos
dados$raca_f <- factor(
  dados$raca,
  levels = c(1, 2, 3),
  labels = c("Branca", "Negra", "Outra")
)

# 2. Definir explicitamente a categoria de referência
dados$raca_f <- relevel(dados$raca_f, ref = "Branca")

# 3. Ajustar o modelo (o R cria k-1 dummies internamente)
modelo <- glm(
  low ~ lwt + smoke_f + raca_f,
  family = binomial(link = "logit"),
  data = dados
)

Insurance$Group <- factor(Insurance$Group, ordered = FALSE)

# offset(log(Holders)) controlando o modelo pelo tamanho desigual da base de clientes em cada grupo
modelo_seguro <- glm(
