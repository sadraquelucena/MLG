Teste de Wald e intervalos de confiança

Introdução

  • Na aula anterior, utilizamos o Teste da Razão de Verossimilhanças (TRV) para avaliar a significância global dos coeficientes de regressão, comparando o modelo completo com o modelo nulo.
  • O teste global avalia as hipóteses:

\[ \begin{cases} H_0: \beta_1=\beta_2=\cdots=\beta_p=0\\ H_1: \beta_j\neq 0, \quad \text{para pelo menos um } j. \end{cases} \]

  • Quando \(H_0\) é rejeitada no TRV, concluímos que pelo menos um dos coeficientes associados às variáveis preditoras é diferente de zero.
    • Ou seja, pelo menos uma das variáveis preditoras é importante para o modelo.
  • Isso leva a pergunta: Quais coeficientes são diferentes de zero?
    • Isto é, quais variáveis individualmente possuem efeito estatisticamente significativo sobre a resposta?

Teste de Wald para a significância individual

  • Seja \(Y\) a variável resposta e sejam \(x_1,\ldots,x_p\) as variáveis preditoras.

  • Supõe-se que a relação entre \(Y\) e as preditoras seja descrita por um MLG:

\[ \eta_i = \beta_0+\beta_1x_{i1}+\cdots+\beta_px_{ip} = \mathbf{x}_i^\top\boldsymbol{\beta}, \]

com

\[ g(\mu_i)=\eta_i, \qquad \mu_i=E(Y_i). \]

  • O vetor de coeficientes é

\[ \boldsymbol{\beta} = (\beta_0,\beta_1,\ldots,\beta_p)^\top. \]

  • Objetivo: avaliar, para cada \(j\), se o coeficiente \(\beta_j\) é estatisticamente diferente de zero.

Hipóteses do teste

  • Para avaliar a significância individual de \(\beta_j\), consideramos

\[ \begin{cases} H_0:\beta_j=0\\ H_1:\beta_j\neq0 \end{cases} \]

  • Sob \(H_0\), a variável preditora \(x_j\) não está associada à resposta por meio do coeficiente \(\beta_j\).

  • Se \(H_0\) for rejeitada, há evidência estatística de que \(\beta_j\neq 0\).

  • Para testarmos essas hipóteses precisamos da distribuição de probabilidade de \(\widehat{\beta}_j\). Para isso usaremos resultados assintóticos.

Distribuição assintótica dos estimadores

  • Sejam \(\widehat{\boldsymbol{\beta}} = (\beta_0, \beta_1, \ldots, \beta_p)^\top\) e \(\widehat{\phi}\) os estimadores de máxima verossimilhança.

  • Para \(n\) suficientemente grande, os estimadores de máxima verossimilhança têm distribuição normal assintótica:

\[ \widehat{\boldsymbol{\beta}} \overset{a}{\sim} N_{p+1}\left(\boldsymbol{\beta}, \boldsymbol{K}_{\beta\beta}^{-1}\right) \]

  • Portanto, para cada \(j=0,\ldots,p\),

\[ \widehat{\beta}_j \overset{a}{\sim} N\left(\beta_j, Var(\widehat{\beta}_j)\right), \] em que \(Var(\widehat{\beta}_j) = \left[\boldsymbol{K}^{-1}_{\beta\beta}\right]_{j+1,j+1}\)

Estatística do teste de Wald

  • Como \(\widehat{\beta}_j \overset{a}{\sim} N\left(\beta_j, Var(\widehat{\beta}_j)\right)\), temos que \[ \frac{\widehat{\beta}_j - \beta_j}{\sqrt{Var(\widehat{\beta}_j)}} \overset{a}{\sim} N(0,1). \]

  • Soba a hipótese nula \(H_0: \beta_j=0\), temos que a estatística \[ W_j = \frac{\widehat{\beta}_j}{\sqrt{Var(\widehat{\beta}_j)}} = \frac{\widehat{\beta}_j}{SE(\widehat{\beta}_j)}\overset{a}{\sim} N(0,1) \] para \(n\) suficientemente grande.

    • \(SE(\widehat{\beta}_j)=\sqrt{Var(\widehat{\beta}_j)}\) é o erro padrão do estimador \(\widehat{\beta}_j\).

Interpretação da estatística de Wald

  • A estatística de Wald \(W_j\) expressa o coeficiente estimado em unidades do seu erro-padrão.
  • Isso significa que:
    • \(W_j \approx 0\): \(\widehat{\beta}_j\) está próximo de zero em relação à sua incerteza;
    • \(|W_j|\) grande: \(\widehat{\beta}_j\) está distante de zero em relação ao seu erro-padrão.
  • Assim, quanto maior \(|W_j|\), maior a evidẽncia contra \(H_0\).
    • Isto é, maior a evidência de que o preditor \(x_j\) está associado à variável resposta.

Regra de decisão no teste de Wald

  • Como \(W_j \overset{a}{\sim} N(0,1)\) sob \(H_0\), para um teste bilateral de nível \(\alpha\), rejeitamos \(H_0\) se \[ |W_j| > z_{1-\alpha/2}. \]

  • Equivalentemente, rejeitamos \(H_0\) se \[ p-\text{valor} = 2 P(Z>|w_j|) < \alpha, \quad Z\sim N(0,1). \]

  • Observação: No summary() do R, a referência utilizada para o \(p\)-valor depende da dispersão. Quando a dispersão é conhecida ou fixada, utiliza-se a Normal padrão; quando é estimada (modelos Poisson e Binomial), utiliza-se a distribuição \(t\) de Student com \(n-p\) graus de liberdade.

Intervalo de confiança para \(\beta_j\)

  • A mesma distribuição assintótica utilizada no teste de Wald permite construir um intervalo de confiança para \(\beta_j\).

  • Como \[ \frac{\hat\beta_j-\beta_j} {SE(\hat\beta_j)} \overset{aprox.}{\sim} N(0,1), \] temos \[ IC_{1-\alpha}(\beta_j) = \hat\beta_j \pm z_{1-\alpha/2} SE(\hat\beta_j) \]

  • Ou, equivalentemente, \[ \left( \widehat{\beta}_j - z_{1-\alpha/2} SE(\widehat{\beta}_j), ~\widehat{\beta}_j + z_{1-\alpha/2} SE(\widehat{\beta}_j) \right). \]

Teste de Wald e intervalo de confiança

  • Para um teste bilateral de nível \(\alpha\), a hipótese \[ H_0: \beta_j = 0 \] é rejeitada quando \[ 0 \notin IC_{1-\alpha}(\beta_j). \]

  • De forma equivalente, \[ p-\text{valor} < \alpha. \]

  • Portanto, o teste de Wald e o intervalo de confiança são duas formas de utilizar a mesma aproximação normal assintótica.

Exemplo 5.1

Regressão Gama (Variável Resposta Contínua Positiva)

  • Dataset: trees (R base)

  • Descrição: 31 cerejeiras-negras, com medições realizadas a 1,37 m do solo.

  • Variáveis:

    • Girth: diâmetro da árvore, em polegadas
    • Height: altura, em pés
    • Volume: volume de madeira, em pés³

Modelo: MLG Gama com ligação logarítmica, tendo Volume como resposta e Girth e Height como preditoras.

Objetivo: O teste da razão de verossimilhanças indicou significância global do modelo \((p<0{,}05)\). Agora, avalie a significância individual dos coeficientes por meio do teste de Wald, ao nível de 5%.

Exemplo 5.1

Teste de avaliação global do modelo:

# Ajuste do modelo completo e nulo
mod_gama_completo <- glm(Volume ~ Height + Girth, family = Gamma(link = "log"), data = trees)
mod_gama_nulo <- glm(Volume ~ 1, family = Gamma(link = "log"), data = trees)

# Teste da razão de verossimilhanças (avaliação global do modelo)
lmtest::lrtest(mod_gama_completo, mod_gama_nulo) # p-valor < 0.05 => ao menos um β é ≠ de zero

Interpretação dos coeficientes de regressão

  • No MLG, \[ g(\mu_i) = \eta_i = \beta_0 + \beta_1x_{i1} + \cdots + \beta_p x_{ip}, \] onde \(\mu_i = E(Y_i)\).

  • Assim, o coeficiente \(\beta_j\) representa a variação no preditor linear (ou seja, no valor transformado \(g(\mu)\)) para cada aumento de uma unidade em \(x_j\), mantendo as demais variáveis constantes.

  • Isto implica que a interpretação de \(\beta_j\) depende da função de ligação utilizada no modelo.

Função de ligação identidade

  • Se \(g(\mu)=\mu\), então \[\mu = \beta_0 + \beta_1x_{1} + \cdots + \beta_p x_{p}\]

  • Nesse caso, \(\beta_j\) representa a variação esperada na média da resposta se aumentarmos uma unidade em \(x_j\), mantendo as demais preditoras constantes.

    • \(\beta_j>0\): um aumento de uma unidade em \(x_j\) está associado a um aumento de \(\beta_j\) unidades na média da resposta.
    • \(\beta_j<0\): um aumento de uma unidade em \(x_j\) está associado a uma redução de \(|\beta_j|\) unidades na média da resposta.

  • Exemplo: \(\quad \widehat{\mu} = 10 + 2x_1 - 0{,}5 x_2\)

    • aumento de uma unidade em \(x_1\) → aumento de 2 unidades na média de \(Y\).
    • aumento de uma unidade em \(x_2\) → redução de 0,5 unidade na média de \(Y\).

Função de ligação logarítmica

  • Se \(g(\mu)=\log(\mu)\), então \[\log(\mu) = \beta_0 + \beta_1x_{1} + \cdots + \beta_p x_{p}\]

  • Aplicando a funçao exponencial para voltar à escala original da resposta: \[ \mu = e^{\beta_0 + \beta_1x_{1} + \cdots + \beta_p x_{p}} = e^{\beta_0}e^{\beta_1x_1}\cdots e^{\beta_px_p} \]

  • Aqui a média varia multiplicativamente com os preditores.

  • Se \(x_j\) aumenta uma unidade: \[ \mu(x_j +1) = e^{\beta_0}e^{\beta_1x_1}\cdots e^{\beta_j(x_j+1)}\cdots e^{\beta_px_p} = \underbrace{e^{\beta_0}e^{\beta_1x_1}\cdots e^{\beta_jx_j}\cdots e^{\beta_px_p}}_{\mu(x_j)} \cdot e^{\beta_j} = \mu(x_j) \cdot e^{\beta_j} \]

  • Portanto, o aumanto de uma unidade em \(x_j\) multiplica a média da resposta por \(e^{\beta_j}\), mantidas as demais preditoras constantes.

Função de ligação logarítmica

  • Exemplo: \(\quad \log(\mu) = 1 + 0{,}095x_1 - 0{,}223x_2 + 1{,}200x_3\)
    • \(e^{0{,}095} = 1{,}10\)
      • aumento de uma unidade em \(x_1\, \Rightarrow\) média de \(Y\) é multiplicada por \(1{,}10\) (aumento de \(10\%\)).
    • \(e^{-0{,}223} = 0{,}80\)
      • aumento de uma unidade em \(x_2\,\Rightarrow\) média de \(Y\) é multiplicada por \(0{,}80\) (\(1-0{,}80=0{,}20\), redução de \(20\%\)).
    • \(e^{1{,}200} = 3{,}32\)
      • aumento de uma unidade em \(x_3\,\Rightarrow\) média de \(Y\) é multiplicada por \(3{,}32\) (\(3{,}32-1=2{,}32\), aumento de \(232\%\)).

Função de ligação logit

  • Na regressão logística a função de ligação é \(g(\mu) = \log\left(\frac{\mu}{1-\mu}\right)\), com \(\mu=P(Y=1)\). Assim, \[ \log\left(\frac{\mu}{1-\mu}\right) = \beta_0 + \beta_1x_{1} + \cdots + \beta_p x_{p} \]

  • Vamos definir \(odds(\mu) = \frac{\mu}{1-\mu}\) razão entre a chance (odds) do evento ocorrer sobre não ocorrer. Assim, \[\log(odds) = \beta_0 + \beta_1x_{1} + \cdots + \beta_p x_{p}\]

  • Aplicando a função exponencial: \[odds = e^{\beta_0 + \beta_1x_{1} + \cdots + \beta_p x_{p}} = e^{\beta_0}e^{\beta_1x_1}\cdots e^{\beta_px_p}\]

Função de ligação logit

  • Se \(x_j\) aumenta uma unidade: \[ \begin{aligned} odds(x_j+1) &= e^{\beta_0}e^{\beta_1x_1}\cdots e^{\beta_j(x_j+1)}\cdots e^{\beta_px_p}\\ &= \underbrace{e^{\beta_0}e^{\beta_1x_1}\cdots e^{\beta_jx_j}\cdots e^{\beta_px_p}}_{odds(x_j)} \cdot e^{\beta_j} = odds(x_j) \cdot e^{\beta_j} \end{aligned} \]

  • Dividindo ambos os lados, obtemos a razão de chances (odds ratio – OR): \[ OR = \frac{odds(x_j+1)}{odds(x_j)} = \frac{odds(x_j)e^{\beta_j}}{odds(x_j)} = e^{\beta_j} \]

  • Portanto, \(e^{\beta_j}\) indica quantas vezes a chance do evento ocorrer aumenta para cada aumento de uma unidade em \(x_j\), mantendo as demais variáveis constantes.

Função de ligação logit

  • Exemplo: \(\quad \log\left(\frac{\mu}{1-\mu}\right) = 1 + 1{,}335x_1 - 0{,}357x_2 + 0{,}140x_3\)
    • \(OR = e^{1{,}335} = 3{,}80\)
      • aumento de uma unidade em \(x_1\, \Rightarrow\) aumenta em 3,8 vezes a chance do evento ocorrer.
    • \(OR = e^{-0{,}357} = 0{,}70\)
      • aumento de uma unidade em \(x_2\,\Rightarrow\) reduz a chance do evento ocorrer em \(30\%\) (\(1-0{,}70=0{,}30\)).
    • \(OR = e^{0{,}140} = 1{,}15\)
      • aumento de uma unidade em \(x_3\,\Rightarrow\) aumenta em 15% a chance do evento ocorrer.

Interpretação dos coeficientes segundo a função de ligação

Função de ligação Modelo na escala transformada Interpretação de \(\beta_j\)
Identidade \(\mu=\eta\) Variação de \(\beta_j\) unidades na média de \(Y\) para +1 unidade em \(x_j\)
Log \(\log(\mu)=\eta\) A média é multiplicada por \(e^{\beta_j}\) para +1 unidade em \(x_j\)
Logit \(\log(\text{odds})=\eta\) As chances são multiplicadas por \(e^{\beta_j}\) para +1 unidade em \(x_j\)

Exemplo 5.5

Utilizando o banco de dados birthwt do pacote MASS (variável resposta low):

  1. Ajuste o modelo completo com todas as variáveis.
  2. Execute o teste de razão de verossimilhanças global (comparando o modelo completo com o modelo nulo).
  3. Faça a seleção de variáveis via Teste de Wald (removendo as não significativas uma a uma).
  4. Valide o descarte via TRV parcial (comparando o modelo reduzido com o completo).
  5. Interprete os \(e^{\hat{\beta}}\) apenas do modelo final reduzido.

Considere um nível de significância de 0,05.
